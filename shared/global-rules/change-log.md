# 全局规则变更记录

## 2026-03-28

- 新增角色分工目录规则。
- 新增编码治理规则。
- 新增开发体系持续演进规则。
- 新增项目配置总表规范。
- 新增 Windows 路径治理规则。
- 明确开发过程中发现的高价值方法，必须作为 `SYSTEM` / `development_system` 候选项记录，而不是口头遗忘。
- 明确编码问题属于交付质量问题，不再视为纯展示问题。

## 2026-03-27

- 新增全局任务分类规则。
- 正式固定三类任务：
  - 业务研发任务
  - 验收协同任务
  - 开发工具相关任务
- 固定两条死规则：
  - 方案讨论不派单
  - 未获明确批准，不主动下发开发工具相关任务
- 明确开发工具相关成果物与业务成果物必须物理隔离存放。
