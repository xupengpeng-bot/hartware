# History README

Status: active
Audience: PM, AI agents
Purpose: make archived task records searchable without mixing them into the live entry chain.

## Rule

Files under `docs/codex/history` are historical records.

They are not active task truth.

## How to use history

Read history only when:

- `CURRENT.md` points to a specific archived task
- PM explicitly asks for a past-wave lookup
- a requirement change needs old execution evidence

## Layout

- `2026-03`
  - archived `COD-*` task sheets and dispatch notes from the March 2026 waves

## First step for history lookups

Open the period README first, then the specific archived task file.
