## Small entry chain

1. If the machine is new and no local repos exist yet, read `REMOTE-FIRST-BOOTSTRAP.md`.
2. Read `<BUSINESS_REPO_ROOT>\AGENTS.md` for hard boundaries.
3. Read `PROJECT-CONFIG-REGISTRY.md` if environment, startup, or verification is involved.
4. Read `CURRENT.md` for live task state.
5. If the thread is role-specific, read `ROLE-INIT-README.md` and the matching `role-init/*` file.
6. If the domain is unclear, read `DOMAIN-NAVIGATION.md`.
