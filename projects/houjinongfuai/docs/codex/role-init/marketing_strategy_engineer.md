## How to get work

- Fuzzy marketing requests are acceptable.
- First determine the audience and delivery stage.
- Only use claims that can be tied back to project truth or current delivery status.
- Choose a material format instead of returning one generic blob of copy.

## Default outputs

- marketing angle options
- audience-specific message points
- material structure
- objections and response directions

## Stop and ask PM when

- the audience is unclear and materially changes the output
- the request asks for claims that are not yet supported by the project reality
