# Hardware Index

Use this directory for board-specific assets.

## Naming Rule

Create one folder per board using:

- `<HARDWARE-SKU>-<REV>`

Current board:

- [SCAN-IRR-CTRL-4G-A01](/D:/Develop/houji/houjinongfuAI-Cursor/hartware/Hardware/SCAN-IRR-CTRL-4G-A01)
- [SCAN-IRR-VALVE-CTRL-4G-A01](/D:/Develop/houji/houjinongfuAI-Cursor/hartware/Hardware/SCAN-IRR-VALVE-CTRL-4G-A01)

## Put Here

- schematics
- pinout images
- board photos
- board-specific flashing bundles
- hardware-only debug notes

## Do Not Put Here

- shared firmware source
- active common protocol implementation
- shared OTA logic

Those stay in:

- [code](/D:/Develop/houji/houjinongfuAI-Cursor/hartware/code)
- [build_flash](/D:/Develop/houji/houjinongfuAI-Cursor/hartware/build_flash)
